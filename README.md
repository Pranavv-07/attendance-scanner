# attendance-scanner
This project is a QR-based Attendance Scanner System for Aditya University.
It uses HTML, CSS, and JavaScript with the html5-qrcode library.
Scan student QR codes to record Roll No, Date, and Time automatically.
Attendance data is displayed in a table on the webpage.
The data can be downloaded as an Excel file for records


Live Preview : https://pranavv-07.github.io/attendance-scanner/
